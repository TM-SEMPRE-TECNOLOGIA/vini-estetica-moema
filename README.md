# Projeto: Vini Estética & Massagem Moema (SP)
## Dossiê Técnico Executivo & Auditoria de Presença Digital 360º

Este repositório contém a documentação técnica e a página editorial de diagnóstico para prospecção estratégica e fechamento comercial com a **Vini Estética & Massagem**, localizada no bairro nobre de **Moema, São Paulo/SP**.

---

### 📂 Estrutura de Arquivos
- **`index.html`**: Página editorial de alto padrão (padrão McKinsey / Bloomberg / TM Sempre Tecnologia) contendo:
  - Cabeçalho institucional fixo com dados do documento, tags de confidencialidade e botões de ação rápida.
  - Seção 01: O fenômeno de Moema e o vazamento de pacientes de alto padrão.
  - Seção 02: Diagnóstico técnico 360º (Google Maps, Instagram @viniestetica, Ausência de Site e Eficiência de Atendimento).
  - Seção 03: Plano estratégico de solução e posicionamento.
  - Seção 04: Matriz de Alinhamento e Calibração (formulário interativo que envia os dados diretamente para o WhatsApp do Thiago).
  - Suporte completo a impressão e geração de PDF (`window.print()` e `@media print`).
- **`ROTEIRO_MENSAGENS_WHATSAPP.md`**: Scripts prontos para envio no WhatsApp, condução da conversa e perguntas para calibrar a precificação perfeita.

### 🚀 Como Publicar no GitHub Pages
1. Crie um novo repositório no seu GitHub com o nome `vini-estetica-moema` (ou nome de sua preferência).
2. Na pasta local `C:\Users\mikaa\Documents\antigravity\vini-estetica-moema`, inicialize o git e faça o push:
   ```bash
   git init
   git add .
   git commit -m "feat: dossie tecnico executivo vini estetica moema"
   git branch -M main
   git remote add origin https://github.com/SEU_USUARIO/vini-estetica-moema.git
   git push -u origin main
   ```
3. No GitHub, vá em **Settings > Pages > Branch: main / (root)** e salve.
4. O link executivo ficará acessível em:
   `https://SEU_USUARIO.github.io/vini-estetica-moema/`

### 🖨️ Como Gerar o PDF Oficial
1. Abra o arquivo `index.html` em qualquer navegador (Google Chrome, Edge ou Brave).
2. Clique no botão **"Imprimir / PDF"** no topo direito (ou use o atalho `Ctrl + P`).
3. Em "Destino", escolha **Salvar como PDF**.
4. Em "Layout", selecione **Retrato**.
5. Em "Mais definições", marque a opção **Gráficos de segundo plano**.
6. Salve o arquivo com o nome: `Dossie-Tecnico-Vini-Estetica-Moema.pdf`.
